# Smart Tesla

**📥 다운로드: [최신 APK (arm64)](https://github.com/moveju112/smart_tesla/releases/latest)**

차량 내 안드로이드 태블릿에서 **BLE로 테슬라를 직접 제어**하는 매크로 앱.

탑승을 감지해 통풍시트를 켜는 식의 조건부 자동화가 목적이다.
기본 제어는 BLE로 처리하며, 사용자 토큰을 등록하면 Fleet API 명령 전송을 선택할 수 있다.
**2025 Model Y (Juniper) 실차에서 연결·키 등록·제어 검증 완료.**

## 지금 되는 것

- 저장 주소 직행 + autoConnect BLE 연결, **ECDH 서명 세션** (공식 테스트 벡터 통과)
- **카드키 태그 키 등록**
- 통풍·열선·공조·잠금·창문·트렁크·충전 명령 + 상태 읽기 (배터리·온도·시트 동기화)
- 매크로 자동화 — 위저드 편집, 시각/시간대/탑승 조건
- 스마트싱스 알림 문구별 빠른 차량 명령 + 스텔스 충전 1회
- **네이버 지도 자동 길안내** — 탑승 시간대별 목적지 안내 (매크로 동작)
- 보닛·트렁크는 **P단에서만** 동작하는 안전 잠금
- 차 없이 전체 흐름을 돌려보는 **시뮬레이터 + 조작판**

## 0.9.162 네이버 안심주행 자동 준비

- 설정 도우미가 무선 페어링 코드·포트를 읽고 연결 포트를 자동 탐색한다. 수동 입력도 유지한다.
- USB 디버깅을 켜고 최초 Wi-Fi 준비 후 지도 실행·종료는 Binder로 처리해 Wi-Fi 연결을 계속 유지하지 않아도 된다.
- 직접 선택한 차량 오디오 연결 시 실행, 연결 해제 30초 뒤 종료한다. 휴대폰 잠금은 유지한다.
- 재부팅·권한 프로세스 종료 후에는 Wi-Fi에서 준비 복구가 필요하다. 자동 실행을 켜면 Wi-Fi 연결 때 복구를 시도한다.
- Android 12 이상 실험 기능이며 실제 네이버 음성·제조사별 호환성은 실기기 확인이 필요하다.
- 설정·검증 범위: [네이버 안심주행 실험](docs/tasks/WIRELESS_NAVIGATION.md).

## 0.9.145 주행 기록 화면 정리

- 다른 기능과 같은 제목 도움말·기록 스위치·설정 행을 사용한다.
- 주행일지·충전 기록은 공통 밑줄 탭으로 이동하며, 저장공간·보관 안내는 설정에서 확인한다.
- 기록이 없는 화면의 큰 배터리 카드를 제거하고 공통 빈 목록 안내를 사용한다.

## 0.9.144 주행·충전 기록

- 기능 → 주행 기록에서 5초 기록을 켠다. 기존 BLE 연결 중 차량 위치·거리·배터리·충전량 등을 기기 내부에 축적한다.
- 주행별 지도·시간·거리·배터리 변화와 충전 이력·전력 그래프를 제공한다.
- 배터리 효율은 km/%로 표시하며 사용 가능 배터리 용량을 입력하면 소모 kWh·km/kWh를 추정한다.
- 5분 단위 GZIP 무손실 압축 + SQLite 트랜잭션. 원본 표본은 자동 삭제하지 않는다.
- 휴대 모드의 기존 연결 제한을 유지한다. 새 BLE 필드 수신·연속 주행 기록은 실차 확인이 필요하다.
- 상세: [주행 기록 저장·지표](docs/tasks/VEHICLE_HISTORY.md).

## 0.9.126 안정성·사용성 개선

- 매크로 저장을 직렬화·원자적 파일 교체로 처리한다. 저장 실패는 편집 내용과 기존 파일을 유지하며, 초기화 실패는 재시도 화면으로 안내한다.
- 새 차량 연결은 VIN·BLE 주소를 함께 저장하고 이전 차량의 키 등록 승인·오디오 선택을 넘기지 않는다. 차량 검색 실패 뒤 VIN을 수정할 수 있고, 나중에 진행을 선택하면 대기 작업을 취소한다.
- Fleet API를 켜기 전에도 최초 토큰 입력이 보인다. 백업 가져오기는 지원하지 않는 버전을 저장 전에 거부하며, 큰 글씨에서는 백업 버튼을 줄바꿈한다.
- 공용 선택창은 시스템 뒤로가기로 닫히고, 버튼의 최소 48dp 터치 영역·버튼 역할과 입력 오류 접근성 정보를 유지한다.
- '오늘' 예보는 날짜가 바뀌면 다시 읽고, 정확도 없는 최근 위치는 새 측위를 요청한다. 실제 차량 연결·키 등록·자가 업데이트 설치는 실기기 확인이 필요하다.
- 단속카메라 도로 축·진행 경로 개선은 [0.9.125](https://github.com/moveju112/smart_tesla/releases/tag/v0.9.125)에 포함됐으며, 내장 단속 기능은 0.9.161에서 제거했다.

## 빌드

```bash
# 최초 1회 — Android SDK 구성 요소
sdkmanager "platform-tools" "platforms;android-35" "build-tools;35.0.0"

./gradlew :app:assembleDebug
./gradlew test          # 로직 단위 테스트
adb install app/build/outputs/apk/debug/app-debug.apk
```

`ANDROID_HOME`이 필요하다. `local.properties`에 `sdk.dir=`를 적어도 된다.
