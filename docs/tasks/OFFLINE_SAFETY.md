# 오프라인 단속 후보 안내

- 출처: 공공데이터포털 전국무인교통단속카메라표준데이터
  https://www.data.go.kr/data/15028200/standard.do
- `tools/update_safety_cameras.py`는 공식 공개 다운로드를 페이지 단위로 읽고 전체 건수를 확인한 뒤 번들을 교체한다.
- 수집 43,724건 중 속도/속도·신호 단속 구분과 유효 좌표·제한속도를 가진 12,012건 포함.
- 번들: `app/src/main/assets/safety_cameras.json`. 출처·수집 시각·기관별 데이터 기준일 포함.
- 기본 안내는 네트워크 없이 기존 HUD GPS를 공유한다. 사용자가 안내를 켜야 GPS를 구독한다.
- 5초 이상 지난 위치·30m 초과 오차는 안내 불가로 처리한다. 5km/h 미만이나 방향 미확정은 후보를 표시하지 않는다.
- 전방 600m, 방향 차 25도 이하, 횡방향 거리 35m 이하의 가장 가까운 후보만 표시한다.
- 설정 → 주행 → 무료 단속 안내 → 경보 초과속도: 0~30km/h, 1km/h 단위, 기본 +5km/h.
- 후보 제한속도 + 설정값 **이상**이면 최대 10초에 한 번 경고음. 100 제한/+5 설정은 105부터이며 104.99에서는 경보하지 않는다.
- 화면 강조·HUD·경고음이 같은 설정을 사용하고 앱 재실행·설정 백업/복원에도 보존된다. 기기 미디어 음량 적용.
- 안내가 켜진 토큰 포함 빌드는 카메라 주변에서 도로 위치 보정을 보조로 사용한다. 단속 방향 확정·이동식 카메라·전체 도로 제한속도·구간 평균속도 판정은 제공하지 않는다.
- 공식 데이터 페이지와 연결된 포털 이용정책을 읽기 전용으로 확인했다. 데이터셋별 재배포 이용허락 범위를 확정하는 별도 표시는 확인하지 못했다.
  - 데이터셋 페이지의 `license` 메타데이터는 포털 일반 정책(`https://www.data.go.kr/ugs/selectPortalPolicyView.do`)만 가리킨다.
  - 정책은 제3자 권리와 공공누리 유형별 조건을 구분하므로 일반 정책 링크만으로 이 병합 데이터의 재배포 권한을 확정하지 않는다.
- 데이터 최신성은 기관별로 다르며 도로 표지가 항상 우선한다.

## 안내 중 자동 도로 매칭

- `설정 → 주행 → 안내 받기`가 켜지고 빌드에 지도 토큰이 있으면 카메라 후보 근처에서 자동으로 도로 매칭을 사용한다. 안내가 꺼지면 위치 전송을 중단한다. 이전 버전의 별도 매칭 설정값은 무시한다. 설정 화면의 안내 스위치 옆에 경로 전송과 수신 서버를 고지한다.
- 주행 중 저장된 카메라 약 1km 내의 넓은 전방 후보(방향 차 120° 이내, 100m 이내는 후방도 허용)에서만 최근 GPS 2~8개를 요청당 최소 10초 간격으로 `POST https://gps-map.choondoggy.com/v1/match` 본문에 전송한다. 후보 이탈·안내 설정 변경·안내 재시작에도 429/503 대기를 포함한 요청 간격을 유지한다(앱 프로세스 재시작은 제외). 지도 전용 토큰은 Git 제외 `local.properties`의 `roadMatchToken`을 빌드에 주입한다. 없는 빌드는 오프라인으로만 동작한다. **APK에 주입된 토큰은 모든 사용자에게 공유되고 추출 가능하다**. 공개 배포 전 토큰 발급·회전·요청률 제한 정책을 확인한다.
- `matched`·미매칭 0·신뢰도 0.8 이상인 경로의 끝점만 30m/5초 이내에 GPS 위치 보조로 사용한다. `uncertain`/실패/지연/토큰 오류는 오프라인 GPS로 되돌린다. 진단 로그는 요청 주기 요약과 결과 상태 전환만 남기며 좌표·토큰·본문은 기록하지 않는다. 카메라 자료에 단속 방향·도로 ID가 없으므로 매칭도 정확한 단속 도로 확인이 아니다.
- 실서버 호출·실주행 GPS 검증은 별도 승인 전 미실시.

## 후속 개선: 기준일 노출·반복 경보 억제

- 개별 카메라의 기관 자료 기준일이 12개월보다 오래됐거나 미래/누락/파싱 오류이면 화면·HUD에 `자료 기준일 … · 갱신 확인`을 표시한다. 같은 좌표의 여러 레코드는 가장 오래된 기준일을 사용한다. 날짜 표시가 자료의 정확성이나 실제 단속 여부를 인증하지는 않는다.
- 번들 수집일이 6개월보다 오래됐거나 유효하지 않으면 목록 전체의 `목록 수집일 … · 갱신 확인`을 표시한다. 각 날짜는 단말 로컬 날짜를 사용하며, 임계 날짜 당일은 경고하지 않는다. 단말 시계가 틀리면 표시도 틀릴 수 있다.
- 같은 카메라 좌표의 소리는 GPS 흔들림·후보 재진입에도 10분간 한 번만 요청하고, 서로 다른 좌표는 기존 전역 10초 간격을 유지한다. 주행 안내 중지 시 이력 초기화. 실제 ToneGenerator 출력은 JVM에서 검증할 수 없다.
- 공식 OSRM 데모(`https://github.com/Project-OSRM/osrm-backend/wiki/Demo-server`)는 비상업적 합리적 사용·초당 최대 1요청만 허용하고 가용성/지연/지도 갱신을 보장하지 않는다. 실제 주행 좌표를 매초 그 서버로 보내 안전 경보를 의존시키지 않는다. OSMF 공개 타일/지오코딩 서버의 이용조건 역시 상용 주행 매칭 API 허가가 아니다.
- 카메라 원자료에 도로 ID·단속 방향이 없으므로 GPS 측위만 도로에 붙여도 카메라가 같은 도로·같은 방향인지 확정할 수 없다. 신뢰 가능한 도로 링크+카메라 링크 대응, 사업자 키·운영/요금/이용약관 및 위치 전송 고지·동의가 마련될 때 별도 지도 매칭 설계가 필요하다. 이번 작업은 지도 매칭을 구현했다고 주장하지 않는다.
- 공공데이터포털 표준데이터의 `license`는 여전히 포털 일반 정책 링크이며 개별 재배포 조건 확정 근거가 아니다. 공식 페이지 `https://www.data.go.kr/data/15028200/standard.do`를 읽기 전용으로 확인했으나 원본 번들은 재수집·교체하지 않았다.

## 0.9.77 안전성 보강

- 위치 유효기간은 수신 시각이 아니라 GPS 측정 시각 기준이다. 5초 이상·미래 시각·누락/비정상 속도·부정확 좌표는 거부한다.
- 수신 중단은 1초 주기 감시로 감지하며 HUD의 오래된 속도·후보도 지운다. 주행 중 방향 누락, 목록 준비/오류를 안내 없음과 구분한다.
- 안내가 켜져 있으면 대시보드·HUD·경고음은 같은 GPS 속도와 `SafetyState.isOverSpeed`를 사용한다.
- 같은 좌표에서 제한속도가 충돌하는 12개 그룹은 임의 속도를 고르지 않는다. `제한 확인 필요`를 표시하고 과속 경보를 보류하므로 도로 표지를 확인해야 한다.
- Android 12+ 위치 권한 재요청은 정확한/대략적인 위치를 함께 요청한다.
- 잘못된 소수 제한속도는 버리고 무한대 수치 한 건 때문에 데이터 갱신 전체가 예외로 종료되지 않게 한다.
- 공공데이터 번들은 재수집·수정하지 않았다. 원자료 최신성·방향·재배포 이용조건은 기존 한계로 남는다.
- 아래 0.9.63 항목은 당시 검증 이력이며, 현재 버전의 실주행 검증을 뜻하지 않는다.
