# 기능 · 설정 탐색 개편 — 0.9.135

## 변경
- 하단/가로 레일을 `기능 · 설정`으로 통일. 기능 목록은 매크로·목적지 전송·단속 안내·스텔스 충전·스마트싱스.
- 실행 스위치는 기능 상세, 연결·권한·옵션은 설정에 배치. 설정 미완료 시 필요한 항목으로 이동하며 돌아와도 자동 실행하지 않음.
- 탭 전환·화면 회전에 선택 기능과 매크로 폴더 유지. 기능 목록 버튼과 시스템 뒤로가기로 상위 이동.
- 목적지 상태 조회 실패를 미연결로 단정하지 않음. 서버에서 확인한 미연결 상태만 연결 설정으로 유도.
- 미등록 기기의 화면 회전 시 차량 등록 화면으로 되돌아가던 상태 초기화도 수정.
- 숨김 처리된 HUD/네이버 자동 실행 기능은 계속 숨김. 기존 GPS 전송 확인 유지.

## Android 15 에뮬레이터 스모크
- 매크로 폴더 → 설정 → 기능 왕복 후 폴더 복원, 미등록 상태 가로 회전 후 화면 유지.
- 미등록 충전 → 차량 설정 → 선택한 충전 기능 복귀, 별도 충전 옵션 설정 진입.
- 위치 권한 부족 → 단속 안내 설정 → Android 권한 창. 복귀 후 꺼짐 유지.
- 단속 안내 켜기 시 GPS 전송 확인 표시, 취소 가능. 실제 안내·차량 제어 실행은 하지 않음.
- 서버 확인 후 미연결 목적지 → 연결 설정 자동 이동, 시스템 뒤로가기로 전송 화면 복귀, 설정 재진입.
- 글자 2배·애니메이션 제거 상태에서 목록 마지막 기능까지 스크롤 접근.
